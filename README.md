# PCB Business Card

A custom business card PCB featuring an LED matrix for custom graphics and animations.

## Project Screenshots

![PCB Front View](3d_viewer_screenshot.png)

## Bill of Materials (BOM)

| Item | Description | Quantity | Link / Footprint |
| :--- | :--- | :--- | :--- |
| 1 | Custom PCB Board (ENIG finish) | 1 | JLCPCB / PCBWay |
| 2 | 0603 LEDs (Matrix) | 16 | [LCSC](https://lcsc.com) |
| 3 | Resistors (Current Limiting) | 4 | [LCSC](https://lcsc.com) |
| 4 | Microcontroller / Driver IC | 1 | [LCSC](https://lcsc.com) |

## Hardware Files
- `business-card.kicad_pcb`: KiCad PCB Layout
- `business-card.kicad_sch`: KiCad Schematic
- `gerbers.zip`: Exported Gerber production files for manufacturing
